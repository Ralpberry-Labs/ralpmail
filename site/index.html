From an API call
to the send queue.

Queue plain-text email with a JSON request. Use a stable idempotency key to retry the same request without adding duplicate jobs.

Read the API reference ↗ 
curl http://127.0.0.1:3000/emails \
  -H "Authorization: Bearer $RALPMAIL_API_KEY" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: receipt-1001' \
  -d '{
    "to": "customer@example.com",
    "subject": "Your receipt",
    "text": "Thank you for your purchase."
  }'
